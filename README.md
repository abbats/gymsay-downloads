# GymSay — Android

**GymSay** — голосовой дневник тренировок: говорите подходы голосом, без рук.
«Эй, тренер, жим под 45, 12 по 25» — подход записан.

Все версии: [Releases](https://github.com/abbats/gymsay-downloads/releases)

### Как установить

1. Откройте скачанный `GymSay.apk`.
2. Если Android спросит — разрешите установку из этого источника (браузер или файловый менеджер).
3. Нажмите **Установить**. Новые версии ставятся поверх старой, данные сохраняются.

Нужен Android 7.0 или новее, 64-битный телефон (arm64).
